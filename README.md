# review-dry-run

Live demo repository for the pull-request review checklist training session.

This branch (`demo-review-branch`) carries a small, single-file change so the
pull request has a real diff to walk through during the session.

## Demo flow

1. Open the pull request from `demo-review-branch` into `main`.
2. Start a review (held as pending).
3. Attach an inline comment on the changed file.
4. Submit the review as a **Comment** (not an approval).
