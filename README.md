This repository is an onboarding demo.

It is used for a live walkthrough of the standard GitHub review flow with a new contributor: create a branch, open a pull request, and leave a comment-only review with an inline comment on a specific line of the changed file.

What to look at during the walkthrough:
- the pull request from the `onboarding-demo-change` branch
- the submitted review on that pull request, which is comment-only (no approval, no change request)
- the inline review comment that begins with "Onboarding note:"

Added on the demo branch: this line exists so the walkthrough has a concrete line of the changed file to attach an inline review comment to.
